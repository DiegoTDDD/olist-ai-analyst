# How many distinct sellers are there in each of the 3 states with the most sellers?

**Decision:** Identify the states with the most sellers to understand market concentration and potential for targeted marketing strategies.
**Metric:** Number of distinct sellers

## Answer

The states with the most sellers are SP with 1849, PR with 349, and MG with 244 distinct sellers.

## Recommendation

Focus marketing efforts on SP and PR, as they have the highest concentration of sellers. Consider strategies to attract more sellers to MG.

## Evidence

```sql
SELECT seller_state, COUNT(DISTINCT seller_id) AS distinct_sellers FROM sellers GROUP BY seller_state ORDER BY distinct_sellers DESC LIMIT 3
```

| seller_state | distinct_sellers |
|---|---|
| SP | 1849 |
| PR | 349 |
| MG | 244 |

## Checks

- SQL passed the read-only checks and ran (3 rows, 1 attempt).
- All numbers in this memo were found in the query result.

## Caveats

The data does not show the total number of sellers across all states, only the top three. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete, so trends should use 2017-01 to 2018-08.
