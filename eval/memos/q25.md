# What share of orders shipped to customers in the seller's own state? Count orders whose first item's seller is in the customer's state.

**Decision:** To understand the efficiency and customer satisfaction of orders shipped to customers in the same state as the seller, which can indicate local delivery advantages.
**Metric:** Proportion of orders where the first item's seller is in the same state as the customer.

## Answer

36.20% of orders shipped to customers in the same state as the seller.

## Recommendation

Invest in local delivery services to improve efficiency and customer satisfaction.

## Evidence

```sql
SELECT ROUND(SUM(CASE WHEN o.customer_state = oi.seller_state THEN 1 ELSE 0 END) / COUNT(*), 4) AS prop_same_state FROM orders o JOIN order_items oi ON o.order_id = oi.order_id WHERE o.purchase_month BETWEEN '2017-01-01' AND '2018-08-01'
```

| prop_same_state |
|---|
| 0.3620 |

## Checks

- SQL passed the read-only checks and ran (1 rows, 1 attempt).
- All numbers in this memo were found in the query result.

## Caveats

This metric does not account for orders where the first item's seller is in a different state. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete, so trends should use 2017-01 to 2018-08.
