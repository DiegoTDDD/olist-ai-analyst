# Which 5 customer states have the highest late delivery rate, among states with at least 1000 delivered orders?

**Decision:** Identify customer states with the highest late delivery rates to focus on improving delivery performance in those areas.
**Metric:** Late delivery rate

## Answer

The states with the highest late delivery rates are SP (18.20%) and RJ (14.95%).

## Recommendation

Focus on improving delivery performance in SP and RJ to reduce late deliveries.

## Evidence

```sql
WITH late_orders AS ( SELECT customer_state, COUNT(*) AS late_count FROM orders WHERE is_late = TRUE AND delivered_at IS NOT NULL GROUP BY customer_state HAVING COUNT(*) >= 1000 ) SELECT late_orders.customer_state, ROUND(SUM(late_orders.late_count) / COUNT(*)::FLOAT, 4) AS late_rate FROM orders JOIN late_orders ON orders.customer_state = late_orders.customer_state WHERE is_late = TRUE AND delivered_at IS NOT NULL GROUP BY late_orders.customer_state ORDER BY late_rate DESC LIMIT 5
```

## Caveats

The data does not show the reasons for late deliveries or trends over time. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete: monthly trends should use 2017-01 to 2018-08. Totals, shares and averages use all orders unless the question names a period.
