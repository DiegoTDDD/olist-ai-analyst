# What is the average review score for late deliveries compared with on-time deliveries?

**Decision:** To understand the customer satisfaction with late deliveries compared to on-time deliveries, we need to calculate the average review score for each delivery status.
**Metric:** Average review score

## Answer

The average review score for on-time deliveries is 4.29, while for late deliveries it is 2.27. The average review score for orders without a delivery status is 1.75.

## Recommendation

Investigate the reasons for late deliveries to improve customer satisfaction and reduce the average review score for these orders.

## Evidence

```sql
SELECT AVG(review_score) AS avg_review_score, is_late FROM orders WHERE review_score IS NOT NULL GROUP BY is_late
```

| avg_review_score | is_late |
|---|---|
| 4.29 | False |
| 2.27 | True |
| 1.75 | None |

## Checks

- All numbers in this memo were found in the query result.

## Caveats

The data does not show the average review score for orders that were not delivered. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete: monthly trends should use 2017-01 to 2018-08. Totals, shares and averages use all orders unless the question names a period.
