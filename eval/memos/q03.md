# What is the average review score for late deliveries compared with on-time deliveries?

**Decision:** To understand the customer satisfaction with late deliveries compared to on-time deliveries, we need to calculate the average review score for each delivery status.
**Metric:** Average review score

## Answer

The average review score for late deliveries is 2.27, while for on-time deliveries it is 4.29. This indicates a significant difference in customer satisfaction between late and on-time deliveries.

## Recommendation

Implement measures to reduce delivery times to improve customer satisfaction and increase review scores.

## Evidence

```sql
SELECT AVG(review_score) AS avg_review_score, is_late FROM orders WHERE review_score IS NOT NULL GROUP BY is_late
```

| avg_review_score | is_late |
|---|---|
| 1.75 | None |
| 2.27 | True |
| 4.29 | False |

## Caveats

The data does not include orders without review scores, so the average review scores may not be representative of all orders. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete: monthly trends should use 2017-01 to 2018-08. Totals, shares and averages use all orders unless the question names a period.
