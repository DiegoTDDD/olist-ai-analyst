# What is the average review score for late deliveries compared with on-time deliveries?

**Decision:** To understand the customer satisfaction with late deliveries compared to on-time deliveries, we need to calculate the average review score for each delivery status.
**Metric:** Average review score

## Answer

The average review score for late deliveries is 2.27, while for on-time deliveries it is 4.29. The average review score for orders without a delivery status is 1.75.

## Recommendation

To improve customer satisfaction, focus on reducing late deliveries. The current average review score for late deliveries is significantly lower than for on-time deliveries, indicating a need for process improvements.

## Evidence

```sql
SELECT AVG(review_score) AS avg_review_score, is_late FROM orders WHERE purchase_month BETWEEN '2017-01-01' AND '2018-08-01' GROUP BY is_late
```

| avg_review_score | is_late |
|---|---|
| 2.27 | True |
| 4.29 | False |
| 1.75 | None |

## Caveats

The data does not provide information on the reasons for late deliveries or the impact of delivery times on customer satisfaction. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete, so trends should use 2017-01 to 2018-08.
