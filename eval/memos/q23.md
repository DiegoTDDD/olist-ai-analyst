# What is the average number of items per order, for orders with at least one item?

**Decision:** To understand the typical size of orders on the Olist marketplace, which can help in inventory planning and logistics.
**Metric:** Average number of items per order

## Answer

The average number of items per order is 1.14.

## Recommendation

This suggests that most orders on the Olist marketplace consist of a single item, which may impact inventory management and logistics strategies.

## Evidence

```sql
SELECT AVG(items) AS avg_items_per_order FROM orders WHERE items > 0
```

| avg_items_per_order |
|---|
| 1.14 |

## Checks

- SQL passed the read-only checks and ran (1 rows, 1 attempt).
- All numbers in this memo were found in the query result.

## Caveats

This metric does not account for the distribution of item sizes or the value of items within orders. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete, so trends should use 2017-01 to 2018-08.
