# What is the average order value (items plus freight paid) for delivered orders?

**Decision:** To understand the financial performance of the e-commerce platform by calculating the average order value for delivered orders.
**Metric:** Average order value (items plus freight paid)

## Answer

The average order value for delivered orders is 159.83 BRL.

## Recommendation

Monitor the average order value to ensure it remains competitive and profitable.

## Evidence

```sql
SELECT AVG(items_value + freight_value) AS avg_order_value FROM orders WHERE status = 'delivered'
```

| avg_order_value |
|---|
| 159.83 |

## Checks

- SQL passed the read-only checks and ran (1 rows, 1 attempt).
- All numbers in this memo were found in the query result.

## Caveats

This metric does not include orders that have not yet been delivered. Orders run from 2016-09-04 to 2018-10-17. 2016 has only a few hundred orders and the months after August 2018 are incomplete: monthly trends should use 2017-01 to 2018-08. Totals, shares and averages use all orders unless the question names a period.
