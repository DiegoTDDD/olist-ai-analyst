# Olist AI analyst

A local-model data analyst that turns a business question into a decision memo, over the real
Olist marketplace data (99,441 orders). Code checks every step the model takes: the SQL, the
result, the trend and every number in the memo. Results of the evaluation are in
[eval/results.md](eval/results.md).

Work in progress: the full write-up follows the first evaluation run.
